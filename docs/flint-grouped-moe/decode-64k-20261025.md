# Flint full-model decode through 64K

Measured 2026-10-25 on one Intel Arc Pro B70, full 49-layer
`mattbucci_Flint-AWQ` checkpoint, Level Zero. All eleven depths completed.
KV capacity was fixed at 65,664 positions for the entire sweep.

Each row averages three timed repetitions of 32 fixed BOS-token decode steps,
after one discarded warmup. Sampling is excluded. Each depth was populated
by actual model prefill. The sliding rings and logits were restored with GPU
copies between repetitions; prefix setup and restore are outside decode timing.

The run uses resident eight-token command graphs, packed-four AWQ decode,
vec4 vocabulary projection, parallel routing, Flash16 with single-exponential
FP32 online softmax, and split16 (the existing depth heuristic increases the
partition count for longer global context). Experimental wider AWQ dispatch
was removed before this run after demonstrating a regression even with width
four selected. Companion binaries were rebuilt to match the restored source.

1691.60/1533.54/1391.71/1214.94 tokens/s respectively.

Exact flags and command are saved in
`.scratchpad/flint-decode-64k-sweep.sh`. Reproduce with:

```bash
docker exec arcaine-dev-run-0b4ca842ff71 bash /workspace/.scratchpad/flint-decode-64k-sweep.sh
```

The script runs:

```bash
./build/arcaine_mbench --model /workspace/models/mattbucci_Flint-AWQ --device 0 \
  -p 512,1024,2048,4096 \
  -d 512,1024,2048,4096,8192,12000,16384,24576,32000,48000,65536 \
  -n 32 -w 1 -r 3 --max-seq 65664
```
